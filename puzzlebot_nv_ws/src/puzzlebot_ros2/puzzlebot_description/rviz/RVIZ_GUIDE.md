# RViz Folder Guide

This folder contains RViz profiles for the robot description package.

## File

- puzzlebot_description.rviz
  - Visualization preset for robot model and TF inspection.

## Why this exists

- Provides a repeatable visualization setup.
- Reduces manual RViz reconfiguration during model development.

## When to use

- Checking link geometry alignment after xacro edits.
- Verifying TF tree and frame naming.
